Lesson 5 · 20 min

Hooks as a guard: before the tool, against deleting and colliding

A permission rule compares text; a hook runs code before every tool and can look at the disk. In this lesson you turn on three PreToolUse guards: one denies the irreversible and the judge's files, another shows how many files an rm would delete and asks for confirmation, and the third warns when another session touched the same file.

Start the lesson

In this lesson you will

  1. 1PreToolUse: deny, ask or nothing, before the tool
  2. 2guarda.py: push forçado, reset --hard, find -delete, arquivos do juiz
  3. 3raio.mjs and colisao.mjs from inema-agent-runtime
  4. 4Test the hook with fake JSON and then in a real session

Goal: turn on a PreToolUse hook that denies the irreversible, asks for confirmation before deleting, and warns about collisions between sessions.

02 · What each guard catches

Three files, three jobs.

1. guarda.py (deny)

Denies what has no way back: forced push, reset --hard, git clean -f, checkout -- ., find -delete, recursive rm on the root or HOME, pkill and killall, dd and mkfs.

It also denies Edit/Write on goal.md, tests/, .claude/ and on the guard's own folder (GUARDA_PROTEGIDOS changes the list).

A real lesson from this machinepkill -f with the pattern on the same shell line killed the shell itself twice (Sept 15 and 16, 2026): that is why pkill is on the list.

2. raio.mjs (ask)

Before rm or git clean, it counts what there would be to delete (git clean runs with -n, list only) and asks for confirmation with the number of files, the size and the first paths.

From inema-agent-runtime (recipe R7). It deletes nothing: it only reads the disk.

3. colisao.mjs (ask)

Before editing, it warns if another session edited the same file in the last 30 minutes, or if it changed from outside (Codex, an editor, a person).

The record is kept in ~/.local/state/inema-runtime/toques.json. The collision strategy (worktree, queue) belongs to course 3.

03 · The hooks in settings.json

The guard goes first, then raio.mjs on Bash; guard and collision on edits. Paths assume both repositories are in ~/projetos.

File · kit/hooks/settings-exemplo.json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Bash",
        "hooks": [
          { "type": "command", "command": "python3 \"$HOME/projetos/loop-r-eng-seguranca-v72/kit/hooks/guarda.py\"", "timeout": 10 },
          { "type": "command", "command": "node \"$HOME/projetos/inema-agent-runtime/runtime/mods/runtime-guarda/hooks/raio.mjs\"", "timeout": 15 }
        ]
      },
      {
        "matcher": "Edit|Write|MultiEdit|NotebookEdit",
        "hooks": [
          { "type": "command", "command": "python3 \"$HOME/projetos/loop-r-eng-seguranca-v72/kit/hooks/guarda.py\"", "timeout": 10 },
          { "type": "command", "command": "node \"$HOME/projetos/inema-agent-runtime/runtime/mods/runtime-guarda/hooks/colisao.mjs\" pre", "timeout": 10 }
        ]
      }
    ],
    "PostToolUse": [
      {
        "matcher": "Edit|Write|MultiEdit|NotebookEdit",
        "hooks": [
          { "type": "command", "command": "node \"$HOME/projetos/inema-agent-runtime/runtime/mods/runtime-guarda/hooks/colisao.mjs\" pos", "timeout": 10 }
        ]
      }
    ]
  }
}

04 · Rehearsal: fake calls, real decisions

The script sends the hooks the same JSON that Claude Code would send and prints the decision. No model involved.

Terminal · guarda.py, raio.mjs and colisao.mjs
[ -d ~/projetos/inema-agent-runtime ] || git clone -q https://github.com/inematds/inema-agent-runtime ~/projetos/inema-agent-runtime
bash ~/projetos/loop-r-eng-seguranca-v72/kit/hooks/provar-guarda.sh
Example from the repository
## guarda.py (nega o irreversível)
git push --force origin main       → deny
git reset --hard HEAD~3            → deny
find . -name '*.o' -delete         → deny
rm -rf ~                           → deny
pkill -f servidor                  → deny
python3 -m pytest -q               → -
Edit tests/test_x.py               → deny
Edit src/app.py                    → -
## raio.mjs (apagar pede confirmação, com a contagem)
rm -r build                        → ask
rm -r nada                         → -
## colisao.mjs (outra sessão editou há pouco)
sessão B edita o mesmo arquivo    → ask
sessão A edita de novo            → -

"-" means no decision: the normal flow (rules and mode) decides. An rm on a folder that doesn't exist asks for nothing, because there is nothing to delete.

A hook that prints a warning as text and exits 0 blocks nothing. What blocks is JSON with permissionDecision (or exiting with code 2, per the docs). Always test through the JSON, as the rehearsal does.
